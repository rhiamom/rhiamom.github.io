How to install

Every tool installs the same way. If you've never installed a Mac app from outside the App Store, follow these steps.

On a Mac

macOS 10.15 Catalina or later. Works on Apple Silicon (M1–M4) and Intel Macs.

Before you start: quit The Sims 2, and back up your neighborhood if you're going to use one of the neighborhood or lot tools.
  1. Download the app. Click its Download for Mac button. Your browser saves a file ending in .dmg to your Downloads folder. A .dmg is a disk image, a bit like a virtual USB stick with the app on it.
  2. Open the .dmg. Double-click it in your Downloads folder (or click it in your browser's download list). A window opens showing the app's icon and an Applications folder.
  3. Drag the app onto the Applications folder in that window. This copies the app onto your Mac. It only takes a few seconds.
  4. Eject the disk image. In the Finder sidebar, click the ⏏ button next to the app's name. You can then put the .dmg in the Trash; you don't need it any more.
  5. Open the app from your Applications folder or Launchpad.
  6. The first time only, macOS asks whether you're sure you want to open an app downloaded from the internet. Click Open. All these apps are signed and checked by Apple, so you won't see an "unidentified developer" warning.
  7. If macOS asks for permission to access your Documents folder or data from other apps, click Allow. The tools need it to read your Sims 2 folders.

To uninstall: drag the app from Applications to the Trash.

To update: download the new version and drag it to Applications again. When the Mac asks, choose Replace. Your settings are kept.

On Windows

SimPE and Road Editor for Windows. 64-bit Windows.

  1. Download the .zip with the Download for Windows button.
  2. Unzip it. Right-click the .zip in File Explorer and choose Extract All…, then Extract. Don't run the program from inside the zip; it won't be able to save.
  3. Run the program from the folder you extracted. The ReadMe in the folder has anything specific to that tool.
  4. If Windows shows "Windows protected your PC", click More info, then Run anyway. Windows says this about programs from small developers that it hasn't seen often; it only appears the first time.

On Linux

SimPE for Linux.

Download the .zip, extract it, and follow the ReadMe inside.

If something goes wrong

  • "The app is damaged and can't be opened" usually means the download didn't finish. Delete it and download it again.
  • Nothing happens when I open the app on a Mac older than macOS 10.15 Catalina: these apps can't run there. Choose Apple menu → About This Mac to see your version.
  • The tool can't find my neighborhoods. Start the game once, so it creates its folders, then quit it and try again.
  • Still stuck? Open an issue on the tool's GitHub page and say which macOS or Windows version you have and what you saw on screen.
